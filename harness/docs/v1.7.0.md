# v1.7.0 — 검표원(cli-ux-inspector) 영입

날짜: 2026-09-18
이전 버전: v1.6.1

## 배경

`codescan tui`의 도움말과 실제 동작이 일치하는지 검수하는 과정에서,
CLI/TUI라는 **사람 대면 표면**을 담당하는 전문가가 정원에 없다는 것이 드러났다.
기존 9명은 파서(regex-safety-guard), AOT(aot-compatibility-scout),
테스트(test-sentinel), 그래프(graph-curator), 웹 뷰어(web-gui-design-reviewer) 등
내부 구조와 웹 표면을 맡고 있으나, 터미널 표면은 비어 있었다.

검수에서 나온 결함들은 모두 "광고한 것을 이행하지 않는" 한 가지 부류였다 —
전문가 한 명이 맡을 수 있는 명확한 영역이다.

## 변경 사항

### 영입: cli-ux-inspector (검표원)

| 항목 | 내용 |
|------|------|
| 타입 | specialist |
| 페르소나 | 검표원 |
| 트리거 | "CLI 검수해", "TUI 검수해", "도움말 검수해", "명령 표면 점검해", "cli ux 점검" |
| 담당 | 도움말↔동작 일치, 키 바인딩 계약, 종료 코드, 취소/확정 경로, 파괴적 동작의 DB 완전성 |
| 비담당 | 기능 설계, 화면 배치·색상, 파서/그래프 내부 (기존 전문가 영역) |

### 신규 파일

- `harness/agents/cli-ux-inspector.md` — 에이전트 정의
- `harness/knowledge/cli-surface-contract.md` — CLI/TUI 표면 계약.
  구조적 함정 3가지(커맨드 뒤 `--help`, 모달 위 전역 키, `IsDefault`),
  Terminal.Gui `FakeDriver` 헤드리스 구동 방법, 파괴적 동작 검수 프로토콜

### 갱신

- `harness/harness.config.json` — `agents`에 `cli-ux-inspector` 추가, version 1.6.1 → 1.7.0

## 첫 수행 결과

영입과 동시에 수행한 첫 검수(`harness/logs/cli-ux-inspector/2026-09-18-0430-tui-help-and-project-crud.md`)에서
결함 7건을 찾아 6건을 수정했다. 특히 **TUI에서 프로젝트 삭제가 키보드로 확정되지 않던 문제**는
마우스가 비활성인 이 앱에서 삭제를 사실상 불가능하게 만들고 있었다.
